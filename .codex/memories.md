# Memories

2026-06-18: `ribs` workspace at `/Users/aklo/projects/ribs` is the Roots in Blue Stone (RIBS) band site — a client web project, redesign of rootsinbluestone.com (Wix), Spotify/dusk.fm app feel. Stack: Next.js 16 + React 19 + Tailwind v4 + shadcn/ui (Base UI, `base-nova`) — first AKLO project using shadcn. Design system is **Bluestone Dark** (deep slate-indigo `#0b0f1a`, frosted glass `.glass`/`.glass-raised`, warm amber `--primary` `#e0a84f`), defined in `app/globals.css`, ported from the `elegant` house style. Band = PA/Poconos duo Walter Lee + Ian Kirk (reggae/rock/blues/soul), scales duo→7-piece. Content is data-driven in `lib/content.ts` and `lib/tour.ts`; merch intentionally excluded.

Aesthetic (2026-06-18 redesign): **monochrome chrome** — black `#060606` base, near-white `#f5f5f6` primary, grayscale + metallic-chrome highlights, no blue/amber. Fonts: Syne display + Geist body + mono labels. Real assets scraped from Wix into `public/` (logo `img/logo.png` used as the wordmark, `img/hero-banner.jpg` grayscale hero, `img/one-last-breath.png` cover floats in hero right column, `gallery/g*.jpg`). Photography is grayscale via `.mono`; album cover left in original color as the single focal accent. Nav has no social icons (Tour Dates + Book Now buttons). Copy is kept to the band's real bio/site wording — avoid inventing marketing copy.

Priorities surfaced top-of-page: tour dates, latest release ("One Last Breath"), booking form. Booking = 5-step rhf+zod form (`components/booking/booking-form.tsx`, schema `lib/booking-schema.ts`) → `POST /api/book` (edge) emails via Resend; only name/email/city required; graceful no-op when `RESEND_API_KEY`/`BOOKING_TO_EMAIL` unset. Music section uses a live Spotify artist embed.
